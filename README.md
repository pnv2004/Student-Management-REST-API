# Student Management REST API

## Overview

A Student Management REST API built using Java and Spring Boot.

This project demonstrates REST API development, CRUD operations, database integration, validation, exception handling, and API documentation.

## Technologies Used

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- H2 Database
- Maven
- REST API
- OpenAPI / Swagger
- JUnit

## Features

- Add student
- View all students
- View student by ID
- Update student information
- Delete student
- Search student information
- Input validation
- Exception handling
- REST API endpoints
- API documentation

## How to Run

### Prerequisites

- Java 17
- Maven

### Run the application

On Windows:

.\mvnw.cmd spring-boot:run

## API

The application provides REST endpoints for student management.

Common HTTP operations:

- GET
- POST
- PUT
- DELETE

## Testing

The REST API can be tested using tools such as Postman.
